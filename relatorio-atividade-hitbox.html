Resposta da atividade - Hitboxes e Particulas



Nesta atividade foi implementado um sistema completo de hitboxes com tres variacoes (retangular simples, composta e circular com matematica propria), alem de particulas de impacto disparadas no momento do hit junto ao som. A solucao foi integrada mantendo baixo acoplamento e seguindo a arquitetura OO do projeto.



1. Hitbox retangular simples (AABB)



Foi criada a classe RectangleHitbox com colisao AABB para objetos simples. Essa e a forma mais comum e mais leve de hitbox.



Exemplo de colisao ponto-retangulo:



public boolean collidesWith(Vector2 point) { 
    return point.x >= x && point.x <= x + width && 
           point.y >= y && point.y <= y + height; 
}


2. Hitbox composta (multiplas partes)



Foi implementada a classe CompoundHitbox, que agrega varias hitboxes. Se qualquer parte colidir, o inimigo inteiro eh considerado acertado. Esse modelo foi usado no boss com corpo, bracos e cabeca.



Exemplo de colisao em hitbox composta:



public boolean collidesWith(Hitbox other) { 
    for (Hitbox hitbox : hitboxes) { 
        if (hitbox.collidesWith(other)) { 
            return true; 
        } 
    } 
    return false; 
}


3. Hitbox circular com matematica propria



A classe CircleHitbox usa matematica propria para colisao. A distancia entre pontos eh calculada com a formula euclidiana, e para colisao com retangulo e usado o ponto mais proximo ao circulo (clamp).



Exemplo de colisao ponto-circulo:



float dx = point.x - position.x; 
float dy = point.y - position.y; 
float distanceSquared = dx * dx + dy * dy; 
return distanceSquared <= (radius * radius);


Exemplo de colisao circulo-retangulo:



float closestX = Math.max(rect.getX(), Math.min(position.x, rect.getX() + rect.getWidth())); 
float closestY = Math.max(rect.getY(), Math.min(position.y, rect.getY() + rect.getHeight())); 
float dx = position.x - closestX; 
float dy = position.y - closestY; 
float distanceSquared = dx * dx + dy * dy; 
return distanceSquared <= (radius * radius);


4. Particulas no momento do hit + som



Quando a flecha acerta um inimigo, particulas sao geradas no ponto de impacto e o som de impacto eh disparado. O efeito usa um pool de particulas e uma pequena explosao radial.



Exemplo de criacao de particulas no impacto:



private void createImpactParticles(float x, float y) { 
    Color[] colors = { Color.RED, Color.ORANGE, Color.YELLOW, Color.YELLOW }; 
    int particleCount = 8; 
    for (int i = 0; i < particleCount; i++) { 
        float angle = (float) (Math.PI * 2 * i / particleCount); 
        float velocityX = (float) Math.cos(angle) * 200f; 
        float velocityY = (float) Math.sin(angle) * 200f; 
        Color color = colors[i % colors.length]; 
        particlePool.obtain(x, y, velocityX, velocityY, 0.5f, 8f, color); 
    } 
}


5. Paredes com hitbox retangular



As paredes da arena foram definidas como retangulos finos usando WallCollider. Isso evita que o player e as flechas atravessem os limites da arena.



Exemplo de paredes alinhadas na arena:



wallLeft = new RectangleHitbox(wallThickness, arenaHeight); 
wallLeft.update(new Vector2(wallLeftX, wallBottomY + arenaHeight / 2f)); 

wallRight = new RectangleHitbox(wallThickness, arenaHeight); 
wallRight.update(new Vector2(wallRightX, wallBottomY + arenaHeight / 2f));
